# OCR engine comparison plan

English | [日本語](benchmark.ja.md)

> The English version is in preparation; the Japanese version is complete.

How the engines are compared on fictional documents: the documents and the ways they're
degraded (resolution, slant, turned pages, JPEG, noise, blur, shadows, photos), how what an
engine read is matched to the truth line by line, the measures (amounts and dates read exactly,
amounts read to the right value, character error rate, lines missed), and how the default
engines and the engine to cross-check them are chosen.
