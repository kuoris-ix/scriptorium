# Security policy

## Reporting a vulnerability

Please report a vulnerability privately, through GitHub's **Report a vulnerability** button on
this repository's Security tab (private vulnerability reporting), not in a public issue.

- Describe what goes wrong and how to reproduce it, with fictional documents only: never attach
  real scans, text read from them, or personal information.
- A problem in an OCR engine itself (YomiToku, PaddleOCR and the others) belongs to that
  engine's project; report it there.

scriptorium is maintained in spare time, so an answer may take a few days. A confirmed
vulnerability is fixed in a new release, with a GitHub security advisory.

## Supported versions

Only the latest release gets fixes. While scriptorium is at 0.x, update to the latest release
to get one.
